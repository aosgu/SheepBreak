# 产品方案（定稿）

## 一句话

Chrome MV3 扩展，每 30 分钟（可调）在当前活跃页面中心铺开一块草地，一群小羊从八方跑进草地活动，附一枚「稍后 10 分钟」按钮。

## 设计原则

提醒的目的是让人起身，不是让人完成任务。因此所有设计都服从三条：

1. **不打断工作流**：不抢焦点、不弹模态、不遮挡可点击区域、无音效
2. **不需管理**：没有打卡、统计、待办，看过即走
3. **可预期**：固定周期，行为不随"是否检测到你在用电脑"而变

## 决策记录

| 决策项 | 结论 | 取舍 |
|---|---|---|
| 计时 | 固定周期 `chrome.alarms`，默认 30 分钟 | 不做久坐检测（不监听键鼠活动），行为可预期、实现最简 |
| 漏播 | 静默跳过，不补偿 | 浏览器最小化、不可注入页面、机器休眠时不追赶 |
| 顺延 | 「稍后 10 分钟」= 单独一次性 alarm 补一次 | 主 30 分钟节奏不变，名副其实；不是"重置整个周期" |
| 提醒强度 | 透明 overlay + 一行轻提示，约 12 秒自动消失 | 不做强制遮罩、不做必须点击才能关闭 |
| 交互 | 仅「稍后 10 分钟」按钮接收点击，其余 `pointer-events: none` | 点击穿透，页面照常可用 |
| 覆盖方式 | 页面中心一块方形草地，四周露出原网页 | 不铺满全屏；草地不透明度 0.9 |
| 羊群动线 | 从视口四边 + 四角 8 个方向跑入，汇聚到中心草地后游荡 | 不局限屏幕下缘横向跑过 |
| 权限 | `<all_urls>` 全站注入 | 安装提示较重，但定时自动触发拿不到 `activeTab`，属硬需求 |
| 免打扰 | 不做 | 无工作时段、无黑名单、无全屏/会议检测，先跑起来看实际体验 |
| 配置 | popup 三项：间隔、总开关、暂停 | 另加「立即看一次」用于验收；不做独立 options 页 |

## 交互时序

```
安装 / 启动
   └─ 注册主 alarm（delay = period = 间隔）
        └─ 触发 → 取当前窗口活跃标签
             ├─ 可注入 → 注入 sheep.js → 草地淡入 → 羊群进场 → 游荡 → 12s 淡出清理
             └─ 不可注入 → 静默跳过
                  ├─ 点「稍后 10 分钟」→ 立即收场 + 注册 10 分钟后一次性补播
                  └─ 不操作 → 到时自动收场，DOM 全部移除
```

主周期只在安装、启动、开启总开关、修改间隔、恢复暂停时重建，重建即重新起算。顺延与暂停使用独立的 alarm 名称，不会覆盖主周期。

## 视觉规格

| 项 | 规格 |
|---|---|
| 草地 | 页面中心正方形，`min(72vmin, 860px)`；1440×900 视口下为 648×648；`opacity: 0.9` |
| 草地内容 | 绿色渐变草底、麦田、树篱、沙土小路、蓝色蜿蜒河、野花；四周手绘羽化纸边 |
| 羊数量 | 9 只，缩放 0.62–0.98 错落 |
| 羊造型 | 内联 SVG 云朵羊毛、深色脸腿与垂耳、脚下软阴影；9 色羊毛（白 / 奶油 / 粉 / 薰衣草 / 薄荷 / 黄） |
| 行为 | `walk`（四腿交替 + 身体颠簸）、`graze`（低头 34°）、`idle`（张望 + 呼吸起伏）随机切换 |
| 节奏 | 进场 2.2 秒（错峰 110ms/只）→ 游荡 → 第 10 秒开始淡出 → 第 12 秒移除 |
| 卡片 | 右下角，米白底、圆角、轻阴影；「起来动一动 / 小羊们来接你啦」+「稍后 10 分钟」 |

## 明确不做（v1 范围外）

- 统计、连续久坐天数、打卡成就
- 工作时段、站点黑名单、全屏/会议检测
- 设置云同步（`chrome.storage.sync`）
- 多标签同步播放（只在当前窗口活跃标签播放）
- 独立 options 页、自定义间隔输入（仅 5 档预设）
- 音效、通知气泡、桌面通知
